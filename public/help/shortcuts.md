# Keyboard shortcuts

On a Mac, use <kbd>⌘</kbd> wherever this page says <kbd>Ctrl</kbd>.

## Story editor

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Find any command, block or analysis tool |
| <kbd>/</kbd> | Add a block after the open one |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save now |
| <kbd>Delete</kbd> | Delete the open block (with an Undo button) |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the open block |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | Move the open block up or down |
| <kbd>Esc</kbd> | Close the open block |
| <kbd>?</kbd> | Show the shortcut list |

Shortcuts that act on blocks don't fire while you're typing in a text box.

In the command search (<kbd>Ctrl</kbd>+<kbd>K</kbd>), use <kbd>↑</kbd> and <kbd>↓</kbd> to choose and <kbd>Enter</kbd> to run.

## Drawing

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Finish the line or area you're drawing |
| <kbd>Backspace</kbd> | Remove the last corner while drawing |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selected shape |
| Double-click | Finish a line or area |

## Tour builder

| Keys | Action |
| --- | --- |
| <kbd>Esc</kbd> | Stop placing a stop on the map |

## Maps

These work in every map, in the editor and for readers.

| Keys or gesture | Action |
| --- | --- |
| Drag | Move the map |
| Scroll wheel (map editor), <kbd>+</kbd> and <kbd>−</kbd> buttons, or pinch | Zoom. Maps in stories don't zoom with the scroll wheel, so readers can scroll the page. |
| Right-drag, or two-finger rotate | Rotate |
| <kbd>Ctrl</kbd>+drag, or two-finger drag up and down | Tilt |
| Arrow keys (after clicking the map) | Move the map |
| <kbd>Shift</kbd>+drag | Zoom to a box |
| Double-click | Zoom in |

## Home screen and help

| Keys | Action |
| --- | --- |
| <kbd>/</kbd> | Search your stories (home screen) or the help (help pages) |
| <kbd>Esc</kbd> | Close a menu or dialog |
